Merkkijono on jono merkkejä. `len()` kertoo pituuden, ja yksittäiseen merkkiin viitataan indeksillä hakasulkeissa. Indeksit alkavat nollasta, ja `[-1]` on viimeinen merkki. Metodit kuten `upper()` palauttavat uuden merkkijonon.

**Sudenkuoppa:** viimeisen merkin indeksi on `len(sana) - 1`, ei `len(sana)`.
