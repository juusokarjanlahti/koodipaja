# Vaatimustenmukaisuus: lait ja hankintaehdot

Tämä kansio kokoaa lait ja hankintaehdot, jotka koskevat Koodipajaa, kun sitä tarjotaan
suomalaisille ammattikorkeakouluille. Tavoite on, että hankintavaiheessa jokaiseen
tavalliseen kysymykseen on valmis vastaus ja dokumentti.

> **Ei oikeudellista neuvontaa.** Yhteenveto on koottu julkisista lähteistä lokakuussa 2026,
> eikä sitä ole tarkistanut juristi. Tarkista ajantasainen lainsäädäntö Finlexistä ja
> käytä juristia ennen ensimmäistä sopimusta.

## Sisältö

- [lait.md](lait.md): kukin laki lyhyesti. Koskeeko se AMK:ta, mitä se vaatii Koodipajalta
  ja mikä on tilanne.
- [hankinta.md](hankinta.md): miten AMK hankkii palvelun (kynnysarvot, sopimusehdot) ja
  tarkistuslista asiakirjoista, joita hankinnassa kysytään.
