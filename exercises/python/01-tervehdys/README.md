# Tervehdys

Kirjoita ohjelma, joka kysyy käyttäjän nimeä ja tervehtii häntä.

Ohjelman tulee ensin tulostaa teksti `Mikä on nimesi?`, lukea nimi omalta riviltään ja
tulostaa sitten `Hei, <nimi>!`.

## Esimerkkiajo

```
Mikä on nimesi?
Aino
Hei, Aino!
```

Vihje: `input()` lukee yhden rivin. Kysymyksen voi tulostaa `print()`-funktiolla tai antaa
suoraan `input()`-funktiolle, kumpikin tapa hyväksytään.
