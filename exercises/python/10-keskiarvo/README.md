# Lukujen keskiarvo

Kirjoita ohjelma, joka lukee kokonaislukuja, kunnes käyttäjä syöttää luvun `0`. Lopuksi
ohjelma tulostaa lukujen keskiarvon kahden desimaalin tarkkuudella muodossa
`Keskiarvo: <luku>`. Nollaa ei lasketa mukaan. Jos yhtään lukua ei syötetty, tulosta
`Ei lukuja`.

## Esimerkkiajo

Syöte:

```
1
2
0
```

Tuloste:

```
Keskiarvo: 1.50
```
