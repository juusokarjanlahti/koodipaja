# Salasana

Kirjoita ohjelma, joka lukee salasanoja rivi kerrallaan, kunnes käyttäjä syöttää oikean
salasanan `avaa`. Jokaisen väärän yrityksen jälkeen tulostetaan `Väärin, yritä uudelleen`.
Kun salasana on oikein, tulostetaan `Tervetuloa!`. Salasanassa isot ja pienet kirjaimet ovat
eri asia.

## Esimerkkiajo

Syöte:

```
kissa
avaa
```

Tuloste:

```
Väärin, yritä uudelleen
Tervetuloa!
```
