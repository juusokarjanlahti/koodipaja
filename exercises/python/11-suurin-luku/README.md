# Suurin luku

Kirjoita ohjelma, joka lukee ensin lukujen määrän ja sitten niin monta kokonaislukua,
kunkin omalta riviltään. Ohjelma tulostaa suurimman luvun muodossa `Suurin: <luku>`.
Toteuta vertailu itse silmukalla, älä käytä `max()`-funktiota.

## Esimerkkiajo

Syöte:

```
3
4
9
2
```

Tuloste:

```
Suurin: 9
```

Vihje: mistä arvosta suurimman luvun etsiminen kannattaa aloittaa, jos kaikki luvut voivat olla negatiivisia?
