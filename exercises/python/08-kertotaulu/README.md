# Kertotaulu

Kirjoita ohjelma, joka lukee kokonaisluvun ja tulostaa sen kertotaulun kertojilla 1–10,
jokainen omalle rivilleen muodossa `<luku> x <kertoja> = <tulo>`.

## Esimerkkiajo

Syöte:

```
3
```

Tuloste:

```
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15
3 x 6 = 18
3 x 7 = 21
3 x 8 = 24
3 x 9 = 27
3 x 10 = 30
```

Vihje: `range(1, 11)` tuottaa luvut 1–10.
