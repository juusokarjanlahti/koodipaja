# Ikäryhmä

Kirjoita ohjelma, joka lukee henkilön iän kokonaislukuna ja tulostaa ikäryhmän:

- alle 18 vuotta: `alaikäinen`
- 18–64 vuotta: `aikuinen`
- 65 vuotta tai enemmän: `eläkeikäinen`

## Esimerkkiajo

Syöte:

```
18
```

Tuloste:

```
aikuinen
```

Vihje: mieti, missä järjestyksessä ehdot kannattaa tarkistaa, ja mitä rajoilla 18 ja 65 tapahtuu.
