# Sanan kirjaimet

Kirjoita ohjelma, joka lukee sanan ja tulostaa kolme riviä: sanan pituuden sekä sen
ensimmäisen ja viimeisen kirjaimen.

## Esimerkkiajo

Syöte:

```
kissa
```

Tuloste:

```
Pituus: 5
Ensimmäinen kirjain: k
Viimeinen kirjain: a
```

Vihje: merkkijonon indeksit alkavat nollasta, ja `sana[-1]` on viimeinen merkki.
