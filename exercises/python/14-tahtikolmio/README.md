# Tähtikolmio

Kirjoita ohjelma, joka lukee kokonaisluvun n ja tulostaa n rivin korkuisen kolmion
tähdistä: ensimmäisellä rivillä on yksi tähti, toisella kaksi ja niin edelleen. Jos n on 0,
mitään ei tulosteta.

**Tässä tehtävässä tuloste tarkistetaan tarkasti,** koska kuvion muoto on itse tehtävä.

## Esimerkkiajo

Syöte:

```
3
```

Tuloste:

```
*
**
***
```

Vihje: Pythonissa merkkijonon voi monistaa: `"*" * 3` on `"***"`.
