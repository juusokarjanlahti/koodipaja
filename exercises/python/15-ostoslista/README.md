# Ostoslista

Kirjoita ohjelma, joka lukee ostoksia rivi kerrallaan, kunnes käyttäjä syöttää tyhjän
rivin. Lopuksi ohjelma tulostaa ostosten määrän muodossa `Ostoksia: <määrä>` ja sen jälkeen
ostokset numeroituina ykkösestä alkaen.

## Esimerkkiajo

Syöte (viimeinen rivi on tyhjä):

```
maito
leipä

```

Tuloste:

```
Ostoksia: 2
1. maito
2. leipä
```
