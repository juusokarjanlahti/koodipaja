# Kahden luvun summa

Kirjoita ohjelma, joka lukee kaksi kokonaislukua, kumpikin omalta riviltään, ja tulostaa
niiden summan muodossa `Summa: <luku>`.

## Esimerkkiajo

Syöte:

```
3
4
```

Tuloste:

```
Summa: 7
```

Vihje: `input()` palauttaa aina merkkijonon. Mitä tapahtuu, jos lasket yhteen kaksi merkkijonoa?
